# 火堆更加忙碌

围绕营火行为和营火遗物扩展的《杀戮尖塔 2》Mod。

当前版本为 `v0.9.7-alpha`，重点改善多人营火稳定性、遗物效果与中英文模组设置，并恢复原版挖掘及房间切换流程。

## 当前已实现

- 古茶具：下一场战斗额外获得 3 点能量。
- 劣质古茶具：下一场战斗额外获得 2 点能量。
- 永恒羽毛：单份治疗量提高到 5 点生命。
- 壶铃：取消整局累计三次的使用限制，可在后续营火继续举重；说明文字不再显示“最多3次”。
- 南瓜蜡烛：存续期间重复添火会增加使用次数并叠加每场战斗的额外能量；熄灭后清零。
- 微型帐篷：商店遗物抽取权重倍率可配置，默认三倍。
- 多人治疗：主动给队友回血后，正确触发治疗者自己的皇家枕头、小邮箱、捕梦网和石炉加湿器；奖励只归治疗者，石炉加湿器使治疗者自己增加5点最大生命值。
- 锻造锤（Forging Hammer）：仅在商店遗物位出现，按稀有遗物定价；成功锻造一张未附魔的牌后，为其添加一个随机且适用的原版正面附魔。
- 异鸟宝宝蛋：获得蛋后永久解锁孵化；蛋的最后存量会写入存档并作为后续每次孵化产生“异鸟俯冲”的数量，每个营火最多孵化一次。
- 所有玩法改动均服从原版好友联机兼容模式。
- 详细测试日志：默认开启，在 `godot.log` 中以 `[测试/Test]` 记录治疗队友、孵化和锻造锤结果，可在模组设置中关闭。

小邮箱、捕梦网、皇家枕头、佩尔的增生组织、切肉刀和南瓜蜡烛的部分基础流程由当前游戏版本原生提供。

## 一键测试遗物

在一局游戏中打开开发者控制台，输入：

```text
busycampfire_test
```

该命令会一次性为输入指令的玩家补齐 BusyCampfire 涉及的全部火堆测试遗物；已经拥有的遗物会自动跳过，不会重复添加。联机时命令会通过游戏的同步指令队列执行。

当火堆选项超过五个时，选项栏会自动等比缩小并保持居中，避免按钮被挤出屏幕；选项减少后会恢复原版尺寸。

## 构建

需要 .NET 9、MegaDot/Godot 4.5.1 Mono、游戏程序集及 BaseLib。配置本机游戏路径后运行：

```powershell
dotnet build
```
