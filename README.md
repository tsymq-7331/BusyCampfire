# 火堆更加忙碌

围绕营火行为和营火遗物扩展的《杀戮尖塔 2》Mod。

当前版本为 `v0.7.0-alpha`，属于第七阶段可构建测试版，并非完整设计稿的最终实现。

## 当前已实现

- 古茶具：下一场战斗额外获得 3 点能量。
- 劣质古茶具：下一场战斗额外获得 2 点能量。
- 永恒羽毛：单份治疗量提高到 5 点生命。
- 壶铃：取消整局累计三次的使用限制，可在后续营火继续举重。
- 南瓜蜡烛：存续期间重复添火会增加使用次数并叠加每场战斗的额外能量；熄灭后清零。
- 克隆：每个火堆的成功使用次数可配置，取消操作不计数。
- 微型帐篷：商店遗物抽取权重倍率可配置，默认三倍。
- 多人治疗：主动给队友回血后，正确触发治疗者自己的皇家枕头、小邮箱和捕梦网；奖励只归治疗者。
- 锻造锤：仅在商店遗物位出现，按稀有遗物定价；成功锻造卡牌后，为其添加随机适用的原版正面附魔；安装 MultiEnchantmentMod 时可继续为已有附魔的牌添加不同附魔。
- 铲子（单人）：正常获得挖掘遗物后，额外进入一个符合当前幕与原版条件的普通单人非战斗事件；使用独立确定性随机数，不消耗原版问号事件随机流。
- 异鸟宝宝蛋：获得蛋后永久解锁孵化；蛋的最后存量会写入存档并作为后续每次孵化产生“异鸟俯冲”的数量，每个营火最多孵化一次。
- 克隆：修正同一营火刷新选项时次数被重置的问题，真正按营火保留已用次数。
- 所有玩法改动均服从原版好友联机兼容模式。

小邮箱、捕梦网、皇家枕头、佩尔的增生组织、切肉刀和南瓜蜡烛的部分基础流程由当前游戏版本原生提供。

## 构建

需要 .NET 9、MegaDot/Godot 4.5.1 Mono、游戏程序集及 BaseLib。配置本机游戏路径后运行：

```powershell
dotnet build
```
